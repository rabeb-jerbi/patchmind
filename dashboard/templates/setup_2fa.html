Configurer la double authentification

La 2FA ajoute une deuxième protection à votre compte. Même si quelqu’un connaît votre mot de passe, il ne pourra pas se connecter sans le code temporaire généré par votre téléphone.

Étape 1 — Préparer l’application

Installez une application d’authentification sur votre téléphone. Elle générera un code de sécurité à 6 chiffres qui change toutes les 30 secondes.

Étape 2 — Scanner le QR code

Ouvrez votre application, choisissez “Ajouter un compte”, puis scannez ce QR code. Si le scan ne marche pas, copiez la clé affichée sous le QR code.

Étape 3 — Confirmer le code

Entrez le code à 6 chiffres affiché dans votre application pour activer définitivement la 2FA.

Pourquoi activer la 2FA ?

  • ✓ Protège votre compte même si le mot de passe est compromis.
  • ✓ Ajoute une vérification par téléphone à chaque connexion sensible.
  • ✓ Réduit fortement le risque d’accès non autorisé.
  • ✓ Recommandé pour les comptes admin et analystes SOC.
